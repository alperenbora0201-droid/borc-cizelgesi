# Borç Çizelgesi

Telefona kurulan aylık borç ve ödeme çizelgesi: krediler, kredi kartı, kira, SGK, çek ve senetler tek yerde.

- Android'de Chrome ile aç, **Uygulamayı yükle**'ye dokun; ana ekranda simgesi olur.
- İnternet olmadan da açılır.
- Borç kayıtları yalnız telefonda saklanır, hiçbir yere gönderilmez. Yedek almak için uygulamadaki **Tam yedek al** düğmesini kullan.
